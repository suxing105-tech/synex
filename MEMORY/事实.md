## 提示词优化技能包（v0.2.36 加的）

- 技能表 `prompt_skills` 多了四列：`source`（`manual` / `md` / `package`）、`package_dir`、
  `package_meta`（JSON 清单）、`package_refs`（真正发给模型的资料文本）。
  老库靠 `PRAGMA table_info` + `ALTER TABLE` 补列，老行补成 `manual`。
- 技能包原样落盘在 `<数据目录>/skills/<技能 id>/`；删技能会连这个目录一起删。
- 注入顺序固定：**正文 → 参考资料 → 输出硬规矩**。资料预算 20000 字符，
  正文里点名过的文件优先；`scripts/` 里的脚本**只当参考文本，不执行**（这条链路没有工具调用循环）。
- 两个导入入口：桌面版 `POST /api/prompt-skills/import-package`（给文件夹路径，后端扫盘）、
  浏览器版 `POST /api/prompt-skills/import-package/upload`（前端读文件内容上传，只送文本类文件）。
- frontmatter 解析是手写的最小实现（不引 yaml 依赖）：`name` / `description` / `license` /
  `allowed-tools` / `version`，其余字段原样存进 `package_meta`。

## 跑打包脚本用 pwsh，不要用 Windows PowerShell

`frontend/scripts/build-sidecar.ps1` 把 PyInstaller 的 INFO 写到 stderr；Windows PowerShell 5.1
在 `$ErrorActionPreference='Stop'` 下会把 native stderr 升成终止性错误，脚本跑到一半就断。
PowerShell 7（pwsh）没有这个行为。跑 `build-sidecar.ps1` / `package-release.ps1` 一律用 pwsh。

## sidecar 找 ffmpeg 的位置（打包时别漏）

`backend/app/media_tools.py` 的查找优先级里，第二条是「`sys.executable` 所在目录」——
也就是 **ffmpeg.exe / ffprobe.exe 必须和冻结后的 `python-backend.exe` 同级**。
NSIS 安装包由 tauri 自己带（externalBin），预览目录得手动拷；漏了的话视频海报帧、音频波形、
容器元数据全废，而视频照样能播，看着像"只坏了一半"。
