# 事实

会变、但当前有效的客观信息。改动任何一项之后记得同步更新本文件。

## 版本

- 当前版本 **0.2.34**（2026-11-14）。
- 版本号共六处，改的时候要一把改齐（仓库自带 `frontend/scripts/bump-version.py`）：
  `backend/app/version.py`、`backend/pyproject.toml`、`frontend/package.json`、
  `frontend/src-tauri/tauri.conf.json`、`frontend/src-tauri/Cargo.toml`、`frontend/src-tauri/Cargo.lock`。

## 技术栈

| 层 | 技术 |
|---|---|
| 桌面壳 | Tauri 2（Rust）+ NSIS `x64` |
| 后端 | Python FastAPI + SQLite / FTS5 |
| 前端 | Svelte 5 + Vite + Tailwind |
| 媒体处理 | 自带 ffmpeg / ffprobe（`vendor/media-tools/`，约 190MB，被 gitignore） |
| 平台 | Windows |

## 端口与启动

- dev 栈：后端 **8897**、前端 **5199**。端口故意跟正式版 sidecar 错开，别手打 README 默认端口。
- 启动脚本：`frontend/scripts/launch-dev.ps1`，支持 `-Restart` / `-Stop` / `-CheckOnly`，
  只碰命令行里带本仓库路径的进程，误伤不到已安装的正式版。
- 日志落在 `outputs/`。

## 测试

- 后端 `pytest`（在 `backend/` 下跑）：**1005 passed / 2 skipped**（2026-11-14）。
- ⚠️ **跑后端测试必须让 ffmpeg / ffprobe 在 PATH 上**，否则海报帧、波形、音视频元数据那批用例会
  集体 `FileNotFoundError`（看着像 100 多个用例坏了，其实是 subprocess 找不到 ffmpeg）。
  仓库自带 `vendor/media-tools/ffmpeg.exe`、`ffprobe.exe`，把它加进 PATH 即可。
