# 决策点

已经确认的设计决定，以及当时为什么这么定。改动碰到这些地方之前先读一眼——
它们多数是踩过坑之后定下来的，不是随手写的。

## 图库与文件

1. **来源目录只登记位置，不复制也不移动任何文件**。它先是一个节点，子目录逐级展开在它下面；
   改它的名字只改图库里的显示标签，磁盘上的真实目录一个字节不动。
2. **「归档」≠「删除」**。右键「归档」只在图库里收起这个目录和里面的素材，磁盘文件与标签都留着；
   恢复在「设置 → 已归档目录」。
3. **只有「我的文件夹」才能连磁盘一起删**（进系统回收站）。那些目录本来就在图库数据目录里，
   来源目录是用户自己的东西，不能替他删。
4. **侧栏计数只有一个口径**：每行显示当前类型的数量，分组标题右边写明"计数 · 音频"。

## 卡片与交互

5. **卡片规范**：画面在上、不透明信息条在下；常态无框，**hover 只放大画面不描边**，只有选中才描边。
6. **hover 一律走底色变化，不用边框高亮**。用户明确反馈过：暗色面板上边框高亮视觉上太突兀。
7. **键盘焦点环单独用品牌红 2px 内描边**，选中环是中性白。两者不能同色——
   卡片被选中时如果焦点环也跟着变白，键盘焦点就等于看不见了。

## 详情面板（2026-11-14 那轮重构后）

8. **取消页签，改成纵向信息层级**：提示词 → 参数 → 队列，一栏滚到底。
   详情区（MetadataCard）整块拆掉，位置能力收进顶栏「更多操作」菜单。
9. **提示词分两套规矩**：原始提示词（工作流原文）走短预览 + 「展开全文」；
   AI 反推提示词反过来，默认就是 350px 一整块、可纵向拖拽改高，不做折叠。
10. **单语复制按钮复制的是当前展示的那种语言**。展示英文时复制出来必须是英文，不能永远是中文那条。

## 代码约定

11. **图标统一**：形状集中在 `frontend/src/lib/icons.ts`；`<Icon size>` 只取 `ICON_SIZES` 档位
    （12/14/16/20/24/36/56），不许随手写新数值；描边只有一把尺子（≤16 → 1.75，≥20 → 2）；
    手写 `<svg>` 只许出现在 `Icon.svelte` 与三个合成徽标（TextWorkspace / MediaPickerModal / VideoPromptPanel）里。
12. **颜色一律引 `frontend/src/app.css` 的 `:root` token**；要透明度用 `--raise-*` / `--shade-*`。
    裸 hex 棘轮**只许降不许升**，基线 722（`design-tokens.test.ts` 守着）。
13. **选中态不要用 `aria-pressed` 配全局 `.fill-interactions`**——那条规则会把按钮整颗刷成品牌红底黑字。
    需要"选中"语义时改用 `aria-current`（CloneModal 就是这么绕开的）。
14. **测试断言别钉死换行符**。仓库在 Windows 上检出的是 CRLF，`\n` 会让这台机器永远红、
    Linux 上永远绿；断言的是排版关系，就用 `\s+`。
