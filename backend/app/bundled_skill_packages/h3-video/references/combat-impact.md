# 力道与防守的证据

模型不会因为写了"很重的一拳"就画出重量。重量和防守都是证据，不是形容词。这一份就是给"证据"用的清单：写完每一击，回来对着这张表补三层东西——路径上的空气、命中瞬间的空气、对方身上的结果。

## 0 三条总原则

- **轻不等于弱，轻等于快而重。** 每一击都有空气反馈，区别只在烈度。连打里每一拳都带空气波纹和拳风，观众潜意识里就认定"这每一拳都很重"。只在重击上写反馈是常见错误，那样轻击就变成假的挥手。
- **格挡不是目的。** 格挡之后的姿势必须能自然接上下一击，写完格挡要顺手写"这个姿势现在正好能发出什么"。
- **特效不是开关，是生长。** 不许"啪地出现"，要从攻击起点就开始微弱可辨，沿轨迹壮大，命中时绽放。

## 1 每一击的空气反馈（五层，逐层补）

### 第一层：路径上的拳风腿风

| 证据 | 轻击版 | 重击版 |
|---|---|---|
| 拳风 | 拳面前方空气微弱扭曲如热浪 | 拳风如利刃切开空气，沿途碎尘被气浪推散 |
| 腿风 | 腿前方空气轻微压缩泛白 | 腿风如鞭横扫，空气被切割出可见弧线 |
| 发丝衣袂 | 攻击路径附近发丝微微飘动 | 发丝衣袂被拳风猛然吹起 |
| 地面碎尘 | 微尘被拳风卷起 | 细碎沙石被压得四散飞溅 |

### 第二层：命中瞬间的气爆（三档）

- 轻击 = 微气爆：肉眼可见的空气波纹从接触点荡开。
- 重击 = 明气爆：空气被撕裂出沉闷音爆，劲气在接触点骤然炸裂，环形气浪向外扩散，脚下碎尘被震弹起。
- 终极击 = 冲击波：环形冲击波从命中点轰然扩散，地面碎裂，碎石尘土被气浪掀起飞散。

### 第三层：命中形态由攻击路径决定（不许混用）

| 攻击路径 | 空气反馈形态 |
|---|---|
| 直线穿刺（冲拳、标指、正蹬、脚尖刺） | 子弹状细长气穴，拳面如弹头击穿空气，留下细长气穴随后崩散 |
| 弧线横扫（摆拳、横肘、鞭腿、横扫踢） | 月牙状气刃轨迹，空气被切割出可见弧线 |
| 垂直下砸（砸肘、下劈腿、千斤坠） | 空气被垂直压下、向两侧翻涌如气帘 |
| 旋转扩散（旋风踢、反背肘、转身鞭拳） | 螺旋气旋，沿腿的弧线扩散 |
| 贴身寸劲（寸拳、崩拳、顶肘） | 接触点空气被骤然压缩后炸开 |

### 第四层：被击者的被动反馈（四种，挑一种以上）

格挡气浪反弹（重击命中格挡的瞬间，气浪从格挡点向两侧反弹溅射如水花）；被击者身后气浪（空气被冲击波推挤出可见气浪）；滑行气轨（被推退滑行时脚下拖出两道尘土气轨）；发丝衣物冲击飘（命中瞬间被击者发丝衣物被冲击气浪向前猛然吹起）。

### 第五层：余波回填（重击之后 0.2–0.3 秒）

回填气流（攻击路径上空气回填，碎尘被卷回聚拢）；发丝回飘（先被拳风吹向前方，攻击过后被回填气流吹回头飘）；空气余震（极重命中后空气残留肉眼可见的震颤）；双人对冲绞杀（两股拳风腿风在中间碰头，空气被挤压成劲气漩涡，碎尘在漩涡中悬浮，发丝衣袂向两侧被气浪吹开）——最后这种是"大招对撞"的标准证据。

### 速度的证据（只有三档，别乱加）

快速 = 残影（动作留下一道半透明残影，0.1 秒消散）；极快 = 气痕加残影（扫过之处空气被切割出可见弧线气痕，0.2 秒消散）；瞬速 = 音爆锥（拳或腿前端形成锥形压缩空气层，空气被撕裂出沉闷音爆）。

## 2 能量特效：先判断该不该写

这套技能服务的模板是参考生视频，角色长相和世界观由用户传的参考图决定。所以：

- **参考图或原文里已经有能量特效设定**（光环、气焰、元素、兵器光效）：可以写，但颜色、质感、形态必须跟参考图一致，不许自己发明一种参考图里没有的属性。
- **参考图里没有特效**：只写物理层——空气、尘、发丝、衣物、形变、汗、声音。这时加能量特效就是跑题，会把写实画面变成动画。
- **写实向（街头、格斗技、武馆）**：连气爆都不必写实化到"可见冲击波"，改用尘、汗珠、衣物抖动、地面打滑、护栏震颤来表达。

### 写特效时的五条铁律

1. 必须有运动方式：不写"紫黑色气焰"，写"紫黑色烈焰缠绕小腿跳动炸裂"。
2. 必须有质感词：浓稠、翻涌、躁动、结晶、霜雾、炽白，一角色一套，不许全篇一个质感。
3. 必须有层次：焰流本体 + 纹理细节 + 外围光晕，至少三层。
4. 必须有听觉层：视觉和听觉双通道。本模板有 `overall_soundscape` 段，特效的声音写在那里，不要塞进正文。
5. 必须绑定身体部位：不写"特效在角色身上"，写"特效缠在小腿上""拳面凝聚"。

### 特效四要素（空间）与生长三段（时间）

空间四要素缺一不可：起源点（拳面凝聚、脚尖浮现、肘尖炸开）；流动形态；终点爆散（冲击波、碎裂、扩散、湮灭）；余韵残留（地面焦痕、空气波纹、余烬、光痕缓缓熄灭）。

流动形态要跟动作类型对得上：直拳寸拳标指正蹬 = 直线穿刺；弧线踢回旋踢摆拳横肘鞭拳 = 弧线切割；旋转类旋风踢反背肘 = 螺旋扩散；下劈砸肘千斤坠 = 垂直坠落；化劲格挡 = 涟漪扩散；终结技 = 四要素全到位。

时间三段：萌芽期（攻击起点，特效微弱但可辨，颜色对、形态对、密度极低，作用是预告"大招来了"，关键词：凝聚、浮现、微弱、若隐若现）；生长期（沿轨迹不断壮大，密度范围亮度递增，关键词：蔓延、增强、拖出、越来越浓）；绽放期（命中瞬间巅峰输出，关键词：全力炸裂、环形冲击波、气浪轰然扩散）。

一次生成的配额：整段里走完整生长三段的特效最多一到两次，全留给终结技。其余用微气爆和残影。

### 三段使命（特效强度不是一条平线）

| 段 | 使命 | 特效 | 像什么 |
|---|---|---|---|
| 前段 | 把人拽进来 | 强但不全力，一招一炸，单击带完整特效弧线，一击即收 | 烟花弹：砰、亮、灭 |
| 中段 | 留住人 | 连打过程零特效保持画面干净，收尾重击带特效当句号 | 鼓点：咚咚咚——砰 |
| 后段 | 炸裂收尾 | 生长三段全开，全程铺满炸 | 烟花秀：点燃、升空、炸开、余烬 |

中段连打零特效是硬规矩：连打时加特效会把画面糊掉、削弱快频的压迫感，但收尾那一下必须有，那是连打的句号。按 `combat-beats.md` 的时间轴骨架映射到本次实际时长，不要照抄 15 秒的秒数。

### 顿挫还是圆活（同一场只让两个人各占一种）

顿挫 = 攻击之间的"断"，每一下独立炸点，打完即收、收完再打。崩拳、砸肘、寸拳、膝顶、鞭拳是顿挫（寸劲类，发力等于爆加收）；刺拳、摆拳、日字冲拳是连绵（速度类，不停顿）；化劲、借力、圆弧动作是反顿挫的圆活（无缝衔接）。两种节奏撞在一起，观众感受到的"刚对柔"就不只是招式不同，而是两套节奏体系在打架——这是武戏最高级的看点，能占到就占。
顿挫的写法：先出左拳，拳面劲气爆发后有明显顿挫，再出右拳，再顿挫，两拳交替。不是连续乱打，是每一拳都有完整的爆与收。

## 3 防守：最容易被模型写崩的地方

模型默认把所有格挡写成"双臂交叉站住"，并且上一格被崩开之后下一格又完好如初。下面这三样东西是专治这个的：什么攻击配什么格挡、越挡越吃力、被打崩之后的过渡态。

### 攻击类型决定格挡方式和姿势（九行，按实际用到的挑）

| 攻击 | 格挡 | 姿势 | 顺势接的反击 |
|---|---|---|---|
| 刺拳直拳（直线中段） | 掌拨偏转 | 侧身、前掌斜拨、后手护胸前 | 拨开的同时身体已转到侧面，正好是腿法蓄力位：拨、转、踢 |
| 摆拳鞭拳（弧线横扫） | 双臂交叉封死 | 双臂交叉于攻击侧，重心微沉 | 交叉后顺势弹开，双臂弹开的方向就是出腿的起势 |
| 横肘砸肘（近身重击） | 双臂上托加后撤半步 | 双臂从下向上托住肘击，身体后倾卸力 | 不是原地硬扛，是托加退 |
| 标指插指（精准刺击） | 侧身闪避加掌拍偏 | 身体侧转让开正面，掌心拍击偏转指路 | 不格挡直接闪，掌拍辅助 |
| 低扫踢扫腿（下盘） | 提膝格挡 | 被扫那一侧膝盖提起、小腿垂直护住 | 膝盖已经提起，等于正蹬或侧踢的蓄力已经完成：挡、蹬 |
| 膝顶（贴身向上） | 下压掌加侧身 | 双掌向下压住膝顶，身体侧转让力泄出 | 双掌在下方，起身时顺势推掌或标指 |
| 正蹬推踢（直线推力） | 双掌接推加滑退 | 双掌接住推力顺势后滑卸力 | 接加滑，力被引走 |
| 下劈腿（垂直重击） | 交叉臂上格加下蹲卸力 | 双臂交叉上举硬接，膝盖弯曲下蹲卸力 | 接住后身体被压得微蹲，这一蹲要写 |
| 旋风踢（水平旋转） | 下潜闪避 | 身体骤然下蹲到攻击线以下 | 蹲下的姿势就是撑地扫腿的蓄力位：潜、扫 |

### 越挡越吃力（四轮递进，不许一直从容）

第 1 轮轻松卸力：重心稳、身体舒展，观众觉得"挡得住"。第 2 轮开始吃力：身体微倾、脚步开始不稳、格挡后后退半步。第 3 轮扛不住：身体弓起、重心被冲击推偏、格挡被崩开。第 4 轮不再硬挡：改成化劲、闪避或反击，从被动承受转为主动化解，观众觉得"翻盘了"。
映射到本次时长：这四轮是相对进度，不是固定秒数，按 `combat-beats.md` 的收缩表摊到实际时长上。

### 防守三态（这是"被打得措手不及"唯一真实的写法）

完整态：双方对峙，防守姿势到位，正式格挡（交叉臂、双掌接推、提膝），姿势稳定、重心稳、动作从容。
崩防线：格挡被破开，双臂被弹开甩向两侧，胸口腹部面部全部暴露。这 0.3–0.5 秒里攻方在连续进攻，守方根本来不及重新架起完整格挡。
过渡态：来不及重建完整防守，只能本能闪避加零碎格挡——闪一下、挡一下、闪一下、挡一下；姿势狼狈、仓促、身体歪斜、重心不稳、脚步碎乱。

过渡态的五种零碎动作（本能反应，不是正式格挡）：侧身闪（上半身猛然侧倾，攻击从身侧擦过）；后仰躲（身体呈弧形后仰，拳从面前一寸飞过）；单臂拍开（一只手仓促拍出，幅度小、不够稳）；撤步让（小步快速后退，重心不太稳）；缩身躲（膝盖弯曲身体缩成一团，从攻击线下方过）。

过渡态的时间规则：轻击破防 0.3–0.5 秒恢复；重击破防 0.5–1 秒，需要两三次零碎防守才逐渐稳住；终结技级不恢复，直接被命中。
过渡态的两种走向：逆转型角色走"闪、拍、闪、挡、重心找回、抓住破绽反击"；压制型角色走"闪、拍、闪、没闪开、被命中"。

### 写法对照（同一段的错与对）

错：正蹬把交叉格挡蹬开，下一个镜头守方又双臂格挡——好像被蹬开这事没发生过。
对：正蹬蹬开交叉格挡，双臂甩向两侧、胸口暴露；攻方冲拳紧跟，守方来不及重建格挡，身体本能侧转躲开拳路；攻方摆拳再扫，守方单臂仓促向外拍开；攻方砸肘轰下，守方歪着身子勉强双臂上托但重心不稳、膝盖微屈；到这之后守方才逐渐稳住，抓住破绽反击。

## 4 身体层面的力道证据（写实向的主力）

没有能量设定时，重量全靠这些：躯干形变（腹部被击中时整个人对折、后背肩胛骨顶起）；重心被推走（双脚在地面滑开半米、脚跟先离地）；头部甩动（下巴被顶到时头向后甩、汗珠被甩出去）；呼吸被顶出去（重击腹部后张口却没有声音，腰立刻弯下去）；接触点皮肤（拳面压进腹肌的凹陷、胫骨陷进大腿外侧）；失衡的手（被推倒时双手在空中乱抓、碰到桌角才借力转身）。
一条经验：受击方的证据写两三条，比攻击方写五条特效更能让人觉得疼。

## 5 交出去前对着这张表自查

- 连打里的每一击都有空气反馈吗（不是只给重击）？
- 每次命中的形态和攻击路径对得上吗（直线穿刺不该出现月牙气刃）？
- 被击者有被动反馈吗？重击之后有 0.2–0.3 秒的余波回填吗？
- 有没有把上一次被破防当成没发生过？破防之后有没有过渡态？
- 防守有没有四轮递进，还是一路从容挡到底？
- 能量特效：参考图里有依据吗？没有的话是不是只写了物理层？
- 中段连打是不是零特效、收尾那一下是不是炸了？
- 两种节奏（顿挫对圆活）用上没有？
- 特效和打击的声音有没有都放进 `overall_soundscape`，而不是塞进正文？
