# 文件夹选择实现记录

日期：2026-09-09；版本：0.2.1。

依据本仓库现有 Tauri、导入弹窗、设置接口和索引器完成实现。规划依据见 39-folder-picker-research.md。

- Rust 注册 Dialog 插件，以主窗口命令封装单目录选择；互斥锁防止重复打开，取消返回 null。初始目录优先使用当前有效绝对路径，再使用上次目录。
- 前端保留手动输入，选择后仅校验，开始导入才保存和扫描；关闭后的异步结果不再覆盖界面。
- 后端目录校验检查存在性、目录类型和读取权限；统一导入保留已有监听目录，规范化去重，共用扫描准入锁。
- 新目录加入现有 Live observer；旧目录继续监听。扫描报告不可访问的子目录。
- 原生窗口实测：成功进入中文子文件夹，确认后正确回填；再次打开定位到当前目录，取消保留原路径。
- 桌面检查未点击开始导入，未额外添加真实用户目录；完整导入和新增图片监听在独立测试数据中验证。

验证结果和交付限制见 outputs/folder-picker-v1/交付说明.md。未发布 GitHub Release，未执行覆盖安装。
