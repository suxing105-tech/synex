# 闪寻空间 (Seek-X) 视觉美化方案

> 2026-11-06 · Product Design 审计 + 方案 · 证据截图：`outputs/product-design-audit-v1/`
> 取证环境：已安装正式版 `F:\闪寻空间\suxing-gallery.exe`（1820×1108），仓库 HEAD 0.2.33。
> 注意：正式版可能落后 HEAD 几个 commit（例如「再次创作」的生成按钮在 HEAD 已是圆形品牌字标，
> 正式版仍是渐变胶囊），逐屏结论以仓库代码为准，截图只作为「用户当前实际看到的样子」。

## 0. 一句话结论

界面不难看，问题在**没有设计系统层**：视觉决定在组件里被重复做了 758 次（244 个不同色值），
所以质感无法稳定；层级又靠「更小的灰标签」而不是表面阶梯与留白，于是媒体型产品反而被灰底压住。
先补 token 层，再动视觉，顺序不能倒——否则美化会在下一个组件里重新失控。

## 2. 保留什么（这套底子是对的，别推翻）

- 朱红 #f24e4e + 暖黑 #0e0e10 的品牌色对：对比 5.04–5.49，splash 的暖墨径向底已经有辨识度。不换色。
- 卡片语言：常态无框无阴影、hover 只推近画面、**只有选中**画描边。克制且正确，媒体优先。
- 缩略图懒生成 + 落盘缓存的性能策略（§7.4）：任何美化不得往列表渲染里加同步重活。
- `prefers-reduced-motion` 已有分支，动效继续走它。

## 3. 方案（P0 → P2，每轮可独立交付）

### P0 地基：设计令牌层（不做这步，后面全部白做）

1. `:root` 建 CSS variables 作唯一来源，`tailwind.config.js` 的 theme 全部引用 `var()`。
2. **墨阶（ink ladder）5 级**，替代现在 9 个混用的黑：
   `canvas #0e0e10` → `rail #141417` → `surface #1a1a1f` → `raised #232329` → `overlay #2c2c33`，
   相邻两级至少 4 L*（现在 rail/canvas 只差约 3，所以三栏糊成一片）。
3. **海拔改用白色叠加**，不再新造 hex：hairline `#ffffff0f`、hover `#ffffff0a`、
   pressed `#ffffff16`、弹层阴影 `0 18px 48px #000a` + 顶部 1px `#ffffff14` 高光内描边。
4. **半径 4 档**：`--r-1 6px`（内联控件）/ `--r-2 10px`（卡片，= 现 `--thumb-radius`）/
   `--r-3 14px`（弹层、设置卡）/ `--r-full`。
5. **字号 6 档 + 行高/字距一起定**：
   `caption 11/1.5` · `label 12/1.5 +0.02em` · `body 13/1.6` · `subhead 15/1.4 600` ·
   `title 18/1.3 600` · `display 22/1.25 600`。**10px/10.5px 全撤**（中文在这个尺寸直接糊）。
6. **文本色 3 档且最低不低于 #9a9aa2**（把上表 6 个不达标全部抬过 4.5）：
   `text-hi #ececf1` · `text-mid #b6b6bd` · `text-lo #9a9aa2`。红底按钮统一 `text-bg` 深墨字。
7. 上闸（符合 §7.5 的特殊测试文化）：加一条后端/前端测试——扫 `frontend/src/**/*.svelte`，
   出现白名单外的裸 hex 即 fail。现有 244 个值先落白名单文件，只减不增。

### P1 观感主体（一轮见效的部分）

1. **自绘 Tooltip 换掉 110 个原生 `title=`**（overlay ink 面板 / 12px / 圆角 6px / 120ms 延迟 /
   键盘焦点也弹）。单这一条就把「网页套壳感」抹掉大半。原生 `title` 保留给 aria 之外的长路径等
   场景可另行决定，但可见 UI 上统一走组件。
2. **图标收敛到 `Icon.svelte` 单一来源**：stroke 统一 1.75，尺寸只允许 14/16/20；
   删掉 ⚙ ＋ ⏳ 📥 这类字符与 emoji（App 侧栏设置键、拖放态两处最明显）。
3. **三栏边界重做**：侧栏/详情栏与 feed 之间用「1px 高光 + 1px 深影」双线代替现在的单条 #2e2e33；
   feed 顶部加 inset 阴影，工具栏才浮得起来。
4. **卡片信息设计**（对 ComfyUI 库最值钱的一刀）：
   - 现状页脚 = 机器文件名 + 像素 + 体积；音频卡还显示波形画布尺寸 `840×360`（无意义）。
   - 改成：第一行 = 提示词首 18 字（设置里可切回文件名），第二行 = **模型徽标 + 尺寸 + 时间**；
     音频卡不再显示宽×高（`footerMetaText` 按 kind 分支）。
   - 页脚底色改用「图片底部 24% 黑渐变」压出信息条，比现在的生硬色块更贴「画面优先」。
   - ⚠️ 硬耦合：卡片高度由 `lib/media-format.ts` 的 `footerHeightFor` 预计算，
     页脚高度/字号一改必须同步改常量，并补一条「两处的值一致」的测试（app.css 注释已警告）。
5. **详情栏从「灰字墙」改成区块卡**：每个区块（AI 反推 / PROMPT / 参数 / 元数据 / 工作流）
   用 surface 卡 + hairline + 12px 标签；参数改两列 key/value grid；顶部身份条
   （缩略图 + 名字 + 模型徽标 + 三个动作）滚动时吸顶。
6. **顶栏利用起来**：现在标题与搜索之间约 700px 空带。左：标题 + 计数；中：搜索（自适应宽）；
   右：类型切换 + 列数滑块 + 详情栏开关。

### P2 精修（第二批）

1. **Lightbox**：两侧现在是大黑洞 + 底部 `1 / 379` 一行。加底部 60px 缩略图胶片条、
   左右邻图预览箭头、玻璃工具条（`backdrop-blur 8px` + ink 60%）、右下浮出模型/尺寸徽标。
2. **空状态**：文本页是一行灰字 + 两个按钮悬在巨大黑场里。补：主标题 + 两个动作 +
   一行快捷键提示 + 一张示意卡（可用 ImageGen 出品牌墨黑/朱红线条插画，或拿真实缩略图拼）；
   同时把 `0` 计数的文件夹默认折叠（当前 46 个目录里大量为 0，纯噪声）。
3. **弹层规范**：overlay 统一 ink 80% + blur 8px；宽度只允许 420/720/1080 三档；
   渐变只留给「生成」这类高光动作，其余主按钮一律 flat accent，避免和 flat 体系打架。
4. **动效规范**：只留三档时长 120 / 180 / 240ms；卡片 hover 推近由 1.09 降到 1.05
   （密集网格里 1.09 偏晃）；扫光骨架保留。
5. **清理**：删除或接回 `HeaderBar.svelte`（当前是死代码，测试还挂在上面，
   会让人以为顶栏有覆盖）。

## 4. 明确不做

- 不换新配色、不上玻璃拟态满屏、不做浅色主题（token 层留好门即可）。
- 不改 `com.suxing.gallery`、不动卡片「选中才描边」的铁律、不在列表渲染里做同步重活。
- 不引入组件库（Radix/shadcn 之类）：现有 Tailwind + 全局 app.css 够，引库反而拆掉现有约定。

## 5. 交付节奏（对齐项目规则）

每轮：**改动 → 针对性测试 → 提交建议（等苏醒 commit 或授权那一次）→ verify-all 全绿 →
build-preview → 启动快捷方式验收**。

- 轮 1（P0）：token 层 + 对比度修正 + Tooltip 组件 + 图标收敛。测试：hex 白名单闸、
  token 对比度单测、tooltip 渲染用例、拼接测试不受影响。
- 轮 2（P1 上）：墨阶 + 三栏边界 + 顶栏。测试：布局常量与样式一致。
- 轮 3（P1 下）：卡片信息设计 + 详情栏区块卡。测试：`footerHeightFor` 一致性 + 卡片渲染用例。
- 轮 4（P2）：Lightbox 胶片条、空状态、弹层与动效规范。
