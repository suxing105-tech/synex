# 本轮修复记录

- 用户明确要求文件夹拥有磁盘实体；旧实现仅创建 folders 表中的分类，因此新增独立 folder_storage 服务，在当前图库 data/folders 下创建目录，返回 path。
- 原有来源目录保持原路径，拖入目标为该路径；旧分类首次接收拖入时建立实体目录，保留原分类 ID。
- 旧版实际窗口显示“视频分镜”16 张，但对应 D:/AI/ComfyUI_windows_313_v0.16.4/ComfyUI/output/视频分镜 中已无文件。这是历史索引未清理，不应显示破损占位。
- 在启动时和运行中每 2 秒核对文件存在性，并广播清理事件；权限错误不作删除处理。现有 watcher 仍优先处理即时删除。
- WebView 原生 tauri://drag-* 事件提供本地路径，按照 devicePixelRatio 换算落点，仅中间缩略图区接受移动；浏览器上传保留文件上传语义，保存到实际选中目录。
- 文件移动使用独占创建目标、同名自动后缀、完成索引后移除原文件；保留图片 ID、收藏、标签。原文件删除失败时回退索引、归属和新建副本。
- 列表请求按发起序号丢弃过期结果；刷新保留已有缩略图，批量移动逐张展示进度。
- 原地新建输入支持 Enter、失焦保存、Esc 取消、中文输入法 Enter 不误提交。
- 左侧顶部改为无边框收起图标；收起后保留窄栏展开按钮。Windows 标题栏通过 DWM 固定 #202020，文字 #e8e8e8。
