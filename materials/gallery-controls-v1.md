# 图库交互调整记录

按用户清单实施：空白双击返回；原图像素复制；移除应用内顶部栏；搜索进入列数工具栏；设置与目录导入移至左下。

复制原逻辑已有原图请求，但 ClipboardItem 不支持某些 MIME 或写入失败时回退复制 URL。现共享 image-clipboard 工具固定请求 /api/images/{id}/file，不带尺寸参数；PNG 直接写入，其他格式按原始宽高转 PNG；点击内即调用 clipboard.write，异步 Blob 作为 Promise。错误明确报告，不调用文本复制回退。图片粘贴提供原始分辨率像素，不承诺保留原格式或元数据。

顶部 HeaderBar 不再挂载；旧组件文件保留。监听目录配置仍在设置中。搜索继续绑定同一 query store。列表改为 flex 自适应剩余高度，移除依赖旧顶栏的固定高度计算。
