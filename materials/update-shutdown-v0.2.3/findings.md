# 更新安装失败诊断

- 本机图库后台进程存在，但 8765 端口已停止监听；pending-update 记录表明 0.2.1 到 0.2.2 已完成准备并生成数据库备份。
- WebSocket 处理器只等待 queue.get，没有并行接收断开消息。空闲时服务器关闭连接后，该处理器仍等待队列，Uvicorn 等待任务结束导致进程不退出。
- Rust 停止后台等待超时后尝试 cancel-update，但服务器已经停止监听，因此再次安装会报 prepare-update / cancel-update 无法连接。
- 新增真实进程测试：连接空闲 WebSocket，执行准备备份及退出。修复前 8 秒超时，修复后成功；全量后端 254 项通过。
- 修复为并行发送事件和等待断开，任一任务结束后取消并回收另一任务；Uvicorn 设置 5 秒 graceful shutdown 超时保障。
- PyInstaller 打包后台已通过相同真实连接回归测试。
- 旧版后台不能通过安装一个尚未运行的新版本修复，因此已卡住的旧版需要关闭图库后覆盖安装；无需卸载。
