# 行内改名和右键所在位置

- 双击名称，直接在左侧原位置编辑；Enter 或失焦保存，Escape 取消。
- 右键文件夹弹出菜单，点击“所在位置”打开对应磁盘目录。
- 来源目录的显示名称可修改，实际磁盘路径保持不变；图库虚拟分类没有磁盘位置，会显示说明。
- 保留单击展开/收起和长按同级排序。

验证：前端 342 项测试、后端 229 项测试通过，类型检查 0 errors（18 项现有 warnings）。已增加空名称、保存失败、中文输入法和打开路径失败的测试。

新版 APP：app/suxing-gallery.exe（需保留同目录 python-backend.exe）。安装包：苏醒图库_0.2.1_x64-setup.exe。本地预览版本保持 0.2.1，未发布线上更新。
