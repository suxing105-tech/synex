# 苏醒图库 0.2.1：文件夹选择

在「导入 ComfyUI 输出目录」窗口点击「选择文件夹」，选择 output 文件夹，再点击「开始导入」。也可以手动输入路径。无需启动 ComfyUI。

取消选择会保留原路径；选择本身不会保存监听设置或开始扫描。导入时保留已有监听目录、避免重复添加，开启 Live 时新目录立即加入监听。无效路径、空目录和部分读取失败会在窗口内提示。

## 安装与交付

- 安装包：`苏醒图库_0.2.1_x64-setup.exe`。
- 安装前关闭所有苏醒图库窗口，包括本次已启动的测试版本；再运行安装包。
- 配套 `.sig` 和 `latest.json` 已生成，通过更新签名验证；尚未上传到 GitHub，线上自动更新目前不会取得此版本。
- 本次启动的是 outputs 下的测试程序，尚未覆盖电脑上已有安装版本。
- 浏览器版保留手动输入；原生选择器适用于桌面版。本版入口为导入窗口。
