# 文件夹与拖放修复版

本地预览版本仍为 0.2.1，未发布自动更新。新版已从本目录 app/suxing-gallery.exe 启动。

## 本轮改动

1. 已从磁盘删除的图片自动移除索引和缩略图。启动核对旧记录，运行期间监听删除并每 2 秒补查漏报；空文件夹的中间区域保持空白。
2. 我的文件夹右侧 + 在左栏原地输入名称。Enter 或失焦保存，Esc 取消。创建的真实目录位于当前图库数据目录的 folders 下；子文件夹在父目录内。右键“所在位置”可打开。
3. Windows 桌面版把 PNG/WebP 图片从资源管理器拖入中间区域，会实际移动到当前选中文件夹；全部图片视图使用收件箱。按图片逐张刷新，同名自动追加后缀，保留收藏和标签，失败回退时保留原文件。浏览器版本受文件权限限制使用上传保存。
4. 左侧顶部原来的根目录新建按钮改成侧栏收起图标，窄栏可再次展开；鼠标悬停只提亮图标。
5. Windows 标题栏固定深黑灰 #202020，避免跟随系统蓝色强调色。

旧版创建的无实体分类在首次接收图片时建立对应目录。来源目录双击仍修改图库显示名；新建的真实“我的文件夹”改名会同步改磁盘目录。
