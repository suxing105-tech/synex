# 苏醒图库：图片对比与快捷操作

- Ctrl 选中两张图片，点击“对比图片”、按 Space，或双击选中图片，进入左右滑动对比。拖动竖线查看差异，可切换“查看单图”。不同尺寸图片保持原比例居中。
- 选中图片后按 Delete，直接删除原文件和对应缩略图；支持多选。对比模式删除两张，单图预览删除当前图片。输入文字时不触发。
- 单图预览时，滚轮向前放大、向后缩小，鼠标位置作为缩放中心；放大后按住左键拖动，点击“适应窗口”复位。

验证：360 项前端测试、244 项后端测试通过，类型检查无错误。当前交付不包含真实用户图片的删除试验。

运行 app/suxing-gallery.exe；app/python-backend.exe 必须放在同一目录。安装版使用本目录的 setup.exe。
