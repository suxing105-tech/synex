# 图片拖入复制与原图拖出修复版

本地预览版 0.2.1，未发布自动更新。新版已从 app/suxing-gallery.exe 启动。

1. 拖入为复制：保留原文件，副本保存到选中文件夹。同名自动加后缀，不覆盖；同一目录重复拖入不生成多余副本。来源图片的图库记录不变。
2. PNG、WebP、JPG、JPEG 均可导入；监听目录与拖入使用相同格式支持。
3. 横竖图片按原比例展示，处理 JPG 的 EXIF 方向；图片加载完成后校正缺失或过时的宽高，预览不裁成统一正方形。
4. Windows 拖出使用原生文件拖放，传递原图片磁盘路径，支持多选；不输出 max=1024 的预览图。拖出使用复制模式保留图库原图。
