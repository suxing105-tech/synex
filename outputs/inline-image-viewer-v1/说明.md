# 中间区域图片细节预览

大图仅展示在中间缩略图区域，移除全屏与模糊背景。左右面板保持可见可操作。

操作：双击缩略图或使用既有预览快捷键打开；适应窗口与 100% 切换；100% 下拖动查看细节；双击图片切换比例；上一张/下一张；返回恢复缩略图滚动位置。Esc 在 100% 下先适应窗口，再按返回。

验证：39 个 Vitest 文件、325 项通过；svelte-check 0 错误、25 项既有警告；生产构建通过。浏览器实测中间区域布局、右侧详情保留、100% 切换和拖动；图片实际显示尺寸 832×1504，与原始尺寸一致。新增测试覆盖切图重置、返回、定位范围与拖动边缘。

Windows 程序：app/suxing-gallery.exe，需与 python-backend.exe 同目录。关闭旧版后打开。未自动化运行原生窗口；未修改后端或图片文件。
