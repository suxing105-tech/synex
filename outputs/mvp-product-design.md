# AI 图库管理器 MVP — 产品设计文档

> 状态：v0.2 · 更新日期：2026-09-02
> v0.2 变更：根据 demo v3 重写功能分级、关键流程、数据模型；新增 UI 布局与快捷键章节

## 1. 背景与目标

随着 ComfyUI 等 AIGC 工作流的普及，个人创作者往往在本地累积数千到数万张 AI 生成图。原生文件管理器只能按文件名查找，无法利用 prompt、模型、seed 等关键元数据快速定位"那张图"。

**目标**：打造一个面向 ComfyUI 用户的轻量级本地图库管理器，让"找回那张图"从分钟级降到秒级。

**核心价值**：基于 prompt 与生成参数的全文检索 + 完整元数据回溯 + 文件夹树形组织 + Live 流式监听。

## 2. 目标用户与场景

| 用户类型 | 主要场景 |
|---------|---------|
| 个人 ComfyUI 重度用户（数千~数万张图） | 复盘调参过程、二次创作、对外展示 |
| AIGC 内容创作者 | 整理 portfolio、为后续创作找参考 |
| AI 绘画研究者 | 对比不同 checkpoint / LoRA / sampler 效果 |

**MVP 仅服务单机、单用户场景**。

## 3. MVP 范围

**包含**
- 三栏布局：左侧文件夹树 / 中间流式输出 / 右侧持久详情
- 本地文件夹监听导入（主：ComfyUI 输出目录），支持 Live 模式监听新增
- PNG / WebP 元数据自动解析（PNG tEXt chunk 离线解析）
- 文件夹树形管理（自定义嵌套子文件夹）
- 缩略图网格 + 缩放滑块
- 详情面板（含快捷复制条）+ Lightbox 大图查看
- 全文搜索 + 标签 + 收藏
- 本地 SQLite 索引 + 原文件原地存放

**不包含（明确排除）**
- 团队协作 / 多用户 / 云同步
- ComfyUI 工作流编辑与重跑
- AI 二次生成（inpainting / outpainting）
- 对外分享、版权水印
- 移动端
- Grid 子图自动拆分入库（放到 P1）

## 4. 功能分级

### P0 — MVP 必须有

| 功能 | 说明 |
|------|------|
| 文件夹监听导入 | 监听指定目录的新增 / 变更，首次扫描建索引 |
| Live 监听模式 | 启动后监听输出目录，新图自动流入 feed 并显示 NEW 徽标 |
| PNG / WebP 元数据解析 | 解析 ComfyUI 写入的 prompt 与 workflow 两个 JSON chunk |
| 缩略图缓存 | 避免重复解码原图 |
| **三栏布局** | 文件夹树 / 流式 feed / 详情面板 |
| **文件夹树管理** | 自定义根文件夹、嵌套子文件夹（无限层级）、重命名、上移 / 下移、删除；子文件夹被删后图片升级到父级 |
| 文件夹递归计数与筛选 | 父文件夹计数 / 筛选包含所有后代 |
| 流式 feed | 按时间倒序展示，新增图片滑入 + 绿色描边动画，3s 衰减 |
| **缩放滑块** | feed 顶部右侧，140~360px 实时调节缩略图尺寸 |
| **Lightbox 大图查看** | 双击 / 空格触发全屏大图；← / → 浏览当前筛选结果；Esc 关闭 |
| 详情面板 | 文件信息头 + 快捷复制条 + Prompt / 反向 Prompt / 参数 / Workflow JSON，**不放图片**（已在 lightbox 解决） |
| **快捷复制条** | 一键复制正向 Prompt / 反向 Prompt / Seed / 完整参数 / Workflow JSON / 全部内容 |
| 文件夹指派 | 详情面板内树状选择器，单击切换（再点取消） |
| 全文搜索 | 顶部搜索框，命中 prompt / 文件名 / 标签 |
| 标签管理 | 详情面板手动添加 / 删除，逗号分隔多标签 |
| 收藏 | ♥ 切换 + 左侧「收藏」系统视图快捷过滤 |
| 系统视图 | 「全部图片 / 收藏 / 最近生成」三个内置只读视图 |

### P1 — 第二版加入

- Grid 子图拆分入库（按 batch 索引每张子图独立条目）

- 文件夹拖拽排序（现为按钮上 / 下移）
- 图片拖拽到文件夹

### P2+ — 后续探索

- 跨设备同步
- 团队共享与权限
- 对外分享链接
- 与 ComfyUI API 双向打通（直接调用生成）
- 移动端

## 5. 关键用户流程

### 5.1 首次使用

1. 用户在 header 点击 ＋ 按钮，弹出导入向导
2. 输入 / 选择 ComfyUI 输出目录
3. 应用扫描目录，建立 SQLite 索引，提取元数据并生成缩略图
4. 扫描完成后跳转到网格视图，Live 默认开启

### 5.2 浏览（feed 中间栏）

1. 默认按时间倒序展示「全部图片」
2. 顶部搜索框输入关键词（命中 prompt / 文件名 / 标签），实时过滤
3. 顶部右侧滑块调节缩略图尺寸（140~360px）
4. 单击缩略图 → 高亮选中，右侧详情更新
5. 双击缩略图 / 选中后按空格 → 打开 lightbox
6. lightbox 内 ← / → 浏览当前筛选结果，Space 跳下一张，Esc 关闭

### 5.3 整理（详情面板）

1. 顶部文件信息头显示文件名 / 尺寸 / 时间 / checkpoint
2. 快捷复制条一键复制常用片段到剪贴板
3. Prompt / 反向 Prompt 完整可滚动查看
4. 生成参数列表（Checkpoint / Sampler / Steps / CFG / Seed / VAE / LoRAs / 尺寸 / 时间 / 文件）
5. ♥ 收藏切换
6. ＋ 标签（逗号分隔多标签）
7. 「所属文件夹」树状选择器，点击切换归属（再点取消）
8. 原始 Workflow JSON 可滚动查看

### 5.4 文件夹管理（左侧）

1. 顶部 ＋ 按钮创建根级文件夹
2. hover 任意用户文件夹 → ⋯ 菜单：重命名 / **新建子文件夹** / 上移 / 下移 / 删除
3. 子文件夹被删除后其下图片自动升级到父文件夹
4. 父文件夹的计数和筛选自动包含所有后代

### 5.5 Live 流式监听

1. header 「● Live」按钮一键开启 / 暂停
2. 开启时 pulse 动画指示在线
3. 新生成图自动插入 feed 顶部，带 NEW 徽标 + 绿色描边 + 滑入动画
4. toast 提示「🆕 新图片已生成：prompt 摘要…」
5. 3 秒后 NEW 标记淡出

### 5.6 找回某张图

1. 记得 prompt 中的某个词 → 顶部搜索 → 命中
2. 记得某次跑图用的 LoRA / checkpoint → 左侧文件夹 + 标签 → 缩小范围
3. 完全不记得 → 翻时间线 / 按收藏夹浏览
4. 命中后双击或按空格 → lightbox 看大图，← / → 连续浏览相似结果

## 6. 数据模型概览

```
Image
  id, file_path, file_hash, mtime, size, width, height
  prompt (positive), negative_prompt
  checkpoint, sampler, steps, cfg, seed, vae
  loras (list of {name, weight})
  favorite (bool), imported_at
  folder_id (FK -> Folder.id, nullable)
  tags (list of tag_id)

Folder
  id, name, icon, parent_id (FK self, nullable)
  order (int, 同级排序)
  system (bool, 内置视图标记)

Tag
  id, name
```

- 索引存储：SQLite；元数据 JSON 留原始备份以便回溯
- 缩略图：本地 cache 目录，按 image_id 哈希分片
- 文件夹树深度无限制，通过 parent_id 自引用
- 系统视图（全部 / 收藏 / 最近）不存为普通 Folder，而是逻辑视图

## 8. 快捷键

| 按键 | 上下文 | 行为 |
|------|--------|------|
| 单击 | feed 缩略图 | 选中，右侧详情更新 |
| 双击 | feed 缩略图 | 打开 lightbox |
| Space | 选中状态下 | 打开 lightbox |
| Space | lightbox 内 | 下一张 |
| ← / → | lightbox 内 | 上一张 / 下一张（基于当前筛选结果） |
| Esc | lightbox 内 | 关闭 lightbox |
| Esc | 弹层打开时 | 关闭弹层（模态 / 文件夹菜单 / lightbox，优先级递减） |
| / | 非输入态 | 聚焦顶部搜索框 |
| Enter | 弹层输入框 | 确认提交 |

## 9. 非功能性需求

| 维度 | 目标 |
|------|------|
| 导入吞吐 | 单机 10k 张图首次扫描 < 10 分钟 |
| 浏览流畅 | 1k 缩略图滚动 60fps |
| 搜索响应 | < 200ms |
| Lightbox 切换 | < 100ms |
| 资源占用 | 闲置时内存 < 200MB |
| 可靠性 | 索引可重建，原文件不被修改 |

## 10. 技术选型（待定）

- **形态**：桌面应用（Electron / Tauri）或 CLI 索引器 + Web 前端，待定
- **后端语言**：Python（ComfyUI 生态友好）或 Node.js / Go
- **前端**：demo 用 vanilla JS + CSS Grid 验证布局；正式版可考虑 React / Vue
- **存储**：SQLite + 原文件
- **缩略图**：libvips 或 Pillow
- **Live 监听**：文件系统 inotify / ReadDirectoryChangesW，或定期轮询

## 附录：关键决策记录

- **Grid 拆分**：MVP 整图入库，UI 预览时拆分，拆分入库放到 P1
- **元数据来源**：解析 PNG tEXt chunk（离线），不依赖 ComfyUI 进程
- **目标平台**：待定（桌面 / Web）
- **三栏布局**：左文件夹树 + 中流式 feed + 右详情，固定比例可响应式收窄
- **详情面板不放图**：详情专注元数据与操作，大图查看交给 lightbox，避免双栏视觉重复
- **Lightbox 触发**：单击选中、双击 / 空格放大，避免误触
- **文件夹树结构**：自引用 parent_id + order 字段，支持无限嵌套与同级排序
