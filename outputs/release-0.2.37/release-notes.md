详情面板
- 详情面板整体重构：信息层级重新排布，交互细节逐条调整。

提示词优化技能
- 除了单个 SKILL.md，现在可以直接导入一整个技能包目录
  （Codex 那种 SKILL.md + references/ + scripts/ 结构）。
- 技能包里的正文、参考资料与输出硬规矩分开处理，注入顺序固定；
  子目录里的 SKILL.md 算参考资料，脚本只当参考文本、不执行。
- 资料预算 2 万字，点名越具体的排越前。

素材选择器
- 「选一张参考图」弹窗左侧新增文件夹分类，按「来源目录 / 我的文件夹」分组，
  点哪一类只看哪一类，每行右侧只数当前这一族。
- 选择器打开时右侧详情栏自动让位，关掉后恢复原状。
