# 苏醒图库：图片反推实施说明

## 使用

1. 左下角「⚙ 设置」→「模型与反推」。
2. 输入配置名称、Base URL、模型 ID、API Key、超时，保存模型。首项自动成为默认模型。
3. 可用「测试图片识别」发送内置白底红色方形测试图。该操作调用服务，可能按服务商规则计费。
4. 可编辑反推指令、选择默认模型，点击「保存反推偏好」。
5. 选择图库图片，在右侧「AI 反推提示词」选择模型并点击反推。
6. 中文 / English 页签分别阅读和复制；历史版本保留每次生成和手动编辑结果。

## 已实现接口与数据

- `/api/model-configs`：配置列表、新建；`/{id}`：修改和删除；`/test`：测试当前表单。
- `/api/reverse-prompt-settings`：读取和更新默认模型、反推指令。
- `/api/images/{id}/reverse-prompts`：生成 / 分页历史；`/edits`：编辑另存。
- 新增独立 SQLite 表，启动时幂等建表，原图 Prompt 不被覆盖；删除模型配置不删除历史。
- 每条记录保存中英文本、原始响应、模型快照、实际指令、SHA-256 图片指纹、时间及父版本。
- 模型不按双语格式返回时，保存原始文本并提示用户整理，不伪装为双语成功。

## 默认行为

- Chat Completions 非流式请求；不自动重试。请求超时默认 120 秒，可设 10–600 秒。
- 保留自定义 URL 路径前缀，兼容输入完整 `/chat/completions` 地址。
- HTTPS 远程地址；HTTP 允许 localhost、局域网 IP、`.local` 名称。
- 长边不超过 2048，EXIF 方向校正，透明白底，动画首帧，内存编码 JPEG，不改写原图。
- Windows 密钥按当前用户加密，跨用户/设备需重新配置；其他平台密钥仅在会话中保存。
- 任务以图片 ID 隔离，切图不取消；同图并发返回 409。关闭程序后不自动恢复请求。
- 原图变化或不可读取时，历史版本显示对应旧图片的提示。
- 第一版不含批量反推、供应商原生协议、自动模型发现或全文检索。

## 验证

自动化测试覆盖配置、加密、协议、图像转换、并发、异常、历史、切图、编辑和入口引导。
最终测试计数和桌面打包验证结果见同目录 validation.md。
