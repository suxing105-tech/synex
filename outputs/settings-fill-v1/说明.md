# 设置交互视觉更新

- 设置分类、模型选择、反推中英页签、历史版本：选中为品牌红底色。
- 普通按钮：悬停加深底色；已选中或主要按钮：悬停为较亮品牌底色。
- 输入框、下拉框和文本框：聚焦改变底色，中性边框保持不变。
- 键盘焦点：按钮使用底色和下划线；复选框所在标签使用底色反馈。
- 顶部设置及导入按钮同步改为底色交互。
- 禁用状态不响应悬停，尊重系统减少动画设置。

业务行为和存储方式不变。Windows release 构建通过，新版位于 `outputs/settings-fill-v1/app/suxing-gallery.exe`，配套后端已复制到同目录，两个 EXE 需保持在一起。旧版 EXE 正在运行，未停止或覆盖旧版；关闭旧版后可运行此新版。
